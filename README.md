# Solo Leveling Academy — Gamified Hunter LMS

A dark, gamified learning platform where students level up through ranked courses, XP, and achievements.

## Development

You need [Bun](https://bun.sh) or Node.js to run this project locally.

```sh
bun install
bun run dev
```

## Built with

- [TanStack Start](https://tanstack.com/start)
- TypeScript
- React
- Tailwind CSS v4
- shadcn/ui & Radix UI
